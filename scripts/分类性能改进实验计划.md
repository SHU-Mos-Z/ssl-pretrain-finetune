# 分类性能改进实验计划

本文档汇总 WBC 与 PLGC 两个分类数据集的性能改进实验。表中每项实验均对应一个可独立执行的 Bash 脚本。

## 1. 公共设置

- 条件预训练权重默认为 `records/pretrain_conditioned/20260817_005610/ckpt_last.pth`。
- 默认使用双卡训练，每卡 batch size 为 4；脚本中的 `CUDA_VISIBLE_DEVICES` 可在运行时覆盖。
- WBC 实验结果统一保存到 `records/test_cls_wbc_0818`。
- PLGC 实验结果统一保存到 `records/test_cls_plgc_0818`。
- `augmentation_copies=N` 表示每个原始样本在一个 epoch 中产生 N 个在线空间变换视图，而不是“原图加 N 个副本”。
- `balanced_sampling` 表示使用逆类别频率加权的有放回采样；`none` 表示普通随机采样且不使用类别权重。

### 分类头记号

| 简写 | Bash/Python 参数 | 结构 |
|---|---|---|
| `h0` | `h0_gap_linear` | 最终特征 $Z$ + GAP + Linear |
| `h1` | `h1_attention_mlp` | $Z$ + 空间注意力池化 + MLP |
| `h2` | `h2_dual_scale` | `f_low` 与 $Z$ 的双尺度注意力池化和拼接 |
| `h3` | `h3_multiscale_gated` | `f_low`、`D2` 与 $Z$ 的注意力池化和样本自适应尺度门控 |

## 3. PLGC 分类性能改进实验

PLGC 的 `mse015` 数据使用以下固定划分：

- 训练集：`data/PLGC_class_patch_512x512_overlap_0x0_to_256x256_minmax_finetune_train_p070_20260818`

### 3.1 难例排除等级

难例 JSON 只作用于训练 Dataset。即使 JSON 中出现验证集或测试集样本，也不会从验证集或测试集中删除。

| 等级 | `MODEL_LOW_TRUE_PROB_THRESHOLD` | `MODEL_SMALL_MARGIN_THRESHOLD` | JSON 中难例数 | 当前训练集实际排除数 | JSON 文件 |
|---|---:|---:|---:|---:|---|
| H0 | 不使用 | 不使用 | 0 | 0 | 无 |
| H1 | 0.70 | 0.50 | 45 | 24 | `configs/sample_exclusions/plgc/plgc_hard_cases_epoch051_ptrue-le0p70_margin-le0p50.json` |
| H2 | 0.80 | 2.00 | 63 | 34 | `configs/sample_exclusions/plgc/plgc_hard_cases_epoch051_ptrue-le0p80_margin-le2p00.json` |
| H3 | 0.90 | 4.00 | 97 | 51 | `configs/sample_exclusions/plgc/plgc_hard_cases_epoch051_ptrue-le0p90_margin-le4p00.json` |

H1、H2、H3 表示逐渐增强的排除强度。每条记录通过 `(class_name, stem)` 与训练样本精确匹配。

## 4. 后续阶段参数覆盖

依赖前序实验最佳结果的脚本提供以下环境变量：

| 环境变量 | 默认值 | 用途 |
|---|---|---|
| `SELECTED_HARD_CASE_LEVEL` | `H2` | PLGC 后续实验采用的难例排除等级 |
| `BEST_AUGMENTATION_COPIES` | `2` | W-C 或 P-E 使用的最佳增强副本数 |
| `SELECTED_AUGMENTATION_COPIES` | `2` | W-E/P-F 阶段固定的增强副本数 |
| `SELECTED_BALANCE_MODE` | `balanced_sampling` | 分类头对比阶段固定的类别平衡方式 |
| `BEST_CLASSIFICATION_HEAD` | `h2_dual_scale` | 最终多随机种子实验使用的分类头 |
| `FINAL_SEEDS` | `42 43 44` | 最终实验依次运行的随机种子 |

例如，当 PLGC 的 P-C 系列显示 H1 最优，P-D 系列显示 `copies=4` 最优时，可运行：

```bash
SELECTED_HARD_CASE_LEVEL=H1 \
SELECTED_AUGMENTATION_COPIES=4 \
bash scripts/test_cls_plgc_0818/10_p_f0_bestdata_h0.sh
```
